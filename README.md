# Make the AI Judge Laugh

One line about office life, written to make the AI judge laugh:

> Badge swipe: the only time we are truly on the clock is when we are already off it.

The hook is the badge-swipe paradox — the only moment you are "on the clock" is the exact moment you are already off it. The punch lands in the reversal of the last words.

## Run it

```sh
node main.ts
```

This validates the line (1–200 characters, a single line, no control characters) and writes it, plus a trailing newline, to `/output/entry.txt`.
